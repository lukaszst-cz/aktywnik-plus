# Aktywnik+ 0.3.0 — Daily UX & Reliability

Ta wersja koncentruje się na codziennym użyciu przez dziecko i rodzica oraz na odporności lokalnego pilota na typowe błędy użytkownika.

## Najważniejsze zmiany

- szybki, neutralny podgląd tygodnia dziecka;
- „Powtórz ostatnią aktywność” bez przepisywania danych;
- szybki podgląd rodzica dla wybranego profilu;
- informacja o świeżości kopii danych;
- widoczny status zapisu lokalnego;
- ochrona przed przypadkowym powtórzeniem identycznego wpisu;
- schema danych i kopii v5;
- odświeżony cache PWA.

## Założenia pozostają bez zmian

Aktywnik+ nie tworzy rankingów dzieci, nie śledzi kalorii, masy ciała ani wyglądu i nie ustawia automatycznych norm aktywności. Bieżący pilot nadal przechowuje dane lokalnie na urządzeniu.

## Następny duży etap

Synchronizacja między urządzeniami, prawdziwe konta i role szkoły wymagają uruchomienia backendu oraz testów uprawnień/RLS.
