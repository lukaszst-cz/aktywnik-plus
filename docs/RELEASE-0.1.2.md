# Aktywnik+ 0.1.2 — Pilot

Wydanie stabilizujące publiczny pilot.

## Najważniejsze zmiany

- Aktywnik+ nadal jest bezpłatny; dodano wyłącznie dobrowolne wsparcie autora przez Buy Me a Coffee.
- Wszystkie kluczowe strony prowadzą także do Zielonej Marki dla osób zainteresowanych własną stroną lub prostym systemem.
- Poprawiono walidację dat i czasu aktywności.
- Raporty nie uwzględniają wpisów z przyszłości.
- Import kopii danych jest ograniczony do 2 MB, czyści wadliwe rekordy i ogranicza nadmierne kolekcje.
- Stan z pamięci przeglądarki jest walidowany przy uruchomieniu.
- Dodano testy regresyjne nowych zabezpieczeń.

## Ważne

To nadal lokalny pilot bez kont, wspólnej bazy i synchronizacji między urządzeniami. Formalne wdrożenie szkolne wymaga backendu, produkcyjnych uprawnień i uzgodnionego modelu ochrony danych.
